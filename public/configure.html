What counts as mainstream?

Shown (mainstream)

  • Premier League
  • La Liga
  • Serie A
  • Bundesliga
  • Champions League
  • NBA
  • NFL
  • MLB
  • NHL

Hidden (not mainstream)

  • La Liga 2
  • Serie B
  • 2. Bundesliga
  • League One / Two
  • Regional & county leagues
  • U-20 / U-21 / youth
  • Reserve & B teams
  • Minor league (AHL, G League)

Judged from the match name and competition, not from a fixed list. Famous clubs and the major US leagues are always kept, and a lower-division or youth fixture is hidden even when a big club is named in it (e.g. a reserve side like “Real Madrid Castilla”).

Download JSON file

Nuvio imports collections as JSON text, not a URL. Use Copy JSON and paste it into the app, or Download JSON file and open it if you prefer. The URL below is only a fetch link — open it to copy the raw JSON.

  1. Choose Copy JSON (or download the file).
  2. In the Nuvio app open Settings, then Collections, then Import Collection.
  3. Paste the JSON.

Open this in a browser to copy the raw JSON if the buttons are blocked.
