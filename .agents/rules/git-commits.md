# Git Commit & Push Rule: Mandatory Detailed Messages with Before & After

## Rule: Structured Commits with Measurable Impact

Whenever committing or pushing code in this repository:
1. **Never use generic commit messages.**
2. **Every commit message must include:**
   - A descriptive title (`perf`, `feat`, `fix`, `refactor`).
   - A summary of code changes.
   - A **Before & After** section detailing:
     - Algorithmic complexity before vs after.
     - Latency, memory, or comparison metrics.
     - Behavioral/architectural improvements.
   - Verification status (test results and coverage).
